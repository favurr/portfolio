# FUTURE.md

# Future Ideas

> A collection of ideas, experiments, and long-term goals that are intentionally **out of scope** for the current version.

This document exists to prevent feature creep.

If an idea does not directly improve V1, it belongs here instead of the roadmap.

---

# Philosophy

Ideas are cheap.

Execution is expensive.

This document is not a roadmap.

It is a parking lot for ideas worth revisiting later.

Adding an idea here does **not** mean it will be built.
